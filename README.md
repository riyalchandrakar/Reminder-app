## Features

- Live running clock with fast-forward mode
- Add reminders with date & time
- Native date-time picker with improved UX
- Auto strike-through when reminder time is crossed
- Clean side-by-side layout (Add / List)
- Scrollable reminder list
- Responsive design

## Tech Stack

- Angular (Standalone Components)
- RxJS
- HTML / CSS

npm install
